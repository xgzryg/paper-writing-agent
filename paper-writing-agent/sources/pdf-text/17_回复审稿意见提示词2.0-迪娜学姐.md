回复审稿意见 Response Letter 提示词 2.0 
By 迪娜学姐 ©版权所有 
 
使用说明： 
--- 
1 模型：Claude opus 4.1 thinking （如果是 Claude 官网使用，打开对话框下方的 extended 
thinking；如果是其他平台 poe，选择 thinking 模式；如果是 openrouters，对话框打开
reasoning） ； 
2 按照提示词说明，将你的文章和审稿意见按照结构放置在对应标签下。只替换标黄部分，
方便 AI 识别哪是你的文章内容，哪是审稿意见； 
3 审稿意见，请将需要回复的意见按照审稿人不同，整理成 R1-Q1, R1-Q2, R2-Q1…，方便
AI 识别哪些是必须点对点回复的意见。 
4 如果有些需要补实验，或审稿人询问其他未在稿件中展示的关于本研究的事实，可以在
问题下方用中文简要回复，例如“Primary answer: 我们尝试了聚焦的三维分类以识别那些 
S6 打开且 SF 处于传导状态的粒子子集，但未能分离出这样的粒子类别。” 方便 AI 参考，
给出精准回答。 
5 有些需要文献支撑的回复，AI 中文回复策略会标注[文献支持]，可以在第二轮问答中就单
个问题，让 Claude 利用联网功能帮你查找文献，具体回复，例如“关于以下问题及回复，
请你在回复中帮我查找相关文献，以（作者，年）的形式在response 中引用，并在结尾列
出 reference lists。”并复制粘贴上一轮关于该问题的问答。见提示词 Round 2。 
7 标黄部分全部换成自己的内容，一次性输入。

## General Guidelines 
1. **Response Structure**: 
   - Thank reviewers collectively at the beginning 
   - Address each comment with clear numbering (e.g., Response to R1-Q1) 
   - Quote the original comment briefly, then provide detailed response 
   - Indicate manuscript changes with specific line numbers/figure references 
 
2. **Content Requirements**: 
   - Provide scientifically accurate and detailed responses 
   - Include specific modifications made to the manuscript (quote the revised text) 
   - Reference relevant literature when appropriate 
   - Explain technical details clearly when addressing methodological concerns 
 
3. **Different Types of Comments**: 
   - **Major experimental concerns**: Explain new experiments/analyses performed or 
provide strong scientific rationale if unable to perform 
   - **Minor technical issues**: Describe specific corrections made 
   - **Conceptual/interpretation questions**: Provide thorough scientific explanation with 
literature support 
   - **Writing/clarity issues**: Show exact text revisions 
 
4. **Special Instructions**: 
   - If additional information is needed to answer properly, explicitly state in Chinese: "To 
address this comment adequately, I need: [specific information]" 
   - For disagreements with reviewers, use format: "We appreciate the reviewer's perspective. 
However, we respectfully maintain that... [scientific justification]" 
   - Mark any response that requires new experimental data as: [REQUIRES NEW DATA]
