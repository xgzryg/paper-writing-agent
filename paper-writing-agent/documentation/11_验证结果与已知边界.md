# 验证结果与已知边界

本轮完成材料审读、创建提示词完善、综合 agent 实现、实际脚本测试、独立用户情境试用和迁移安装验证。验证对象是 `package/paper-writing-agent/` 的实际文件；输入中的实验数字和作者均为合成测试材料，不是新的科研分析结果。

## 覆盖与包结构

- 输入：27 个原始文件，其中 19 份 PDF 共 117 页；8 个原 skill 包展开为 44 个文件条目，其中 33 个有效源文件、1 个嵌套 ZIP、10 个系统/编译缓存。
- 实现：1 个主入口、23 个内置分支，共 24 份 `SKILL.md`；原 8 技能有效资源内置，11 个写作分支及 4 个支撑分支补写。
- 元数据：使用本机 skill-creator 的 `quick_validate.py` 实际检查全部 24 份入口，全部通过。该验证器仅是构建工具，不是安装包依赖。
- 链接：实际核查 175 个运行文档的包内相对链接，全部能解析为包内文件；迁移后再次通过相同入口与链接检查。
- 脚本：8 个实际运行 Python 脚本全部语法解析通过；运行目录未包含符号链接、macOS 元数据或 Python 编译缓存。

## 八个合成任务的前向试用

由独立执行 agent 读取成品入口和实际分支，为八个用户请求写出完整回答，主执行者回读结果。这是有限情境试用，不代表所有未来输入或所有模型表现已被证明。

| 情境 | 实际行为 |
| --- | --- |
| Methods 缺伦理/缺失处理/协变量 | 给可讨论大纲和真实缺项，未编正文细节，保留大纲确认 |
| 投稿信缺期刊名且作者未最终批准、有预印本 | 修正首次过度阻断后，可交草稿；保留未知字段、真实预印本状态，未编造作者已批准或无利益冲突 |
| 仅方括号内改写 | 只修改指定英文片段，外部文字保持 |
| 16:9 摘要图先给方案 | 纠正 1200×800 比例，采用 1920×1080；保留三标签和关联边界，未提前生成图像 |
| 正确 Results 段想要五条意见 | 明确数字和表述正确，区分核查结论与可选改写，未凑五个错误 |
| 禁网选刊且要求当前指标 | 修正首次强制联网/索取额外材料后，给三个临时候选；动态指标明确未核实，网站仅标待核入口 |
| 审稿人要求未做的外部验证和校准 | 中文策略+英文回复，已完成与待做状态分开，使用真实段落定位而未编行号/新数据 |
| Discussion 先建议再由作者选择精简 | 实际计数并提出取舍，保留数字、引文和局限，未提前改写正文 |

具体输出在 `validation/behavior_outputs/case-01.md` 至 `case-08.md`。初次发现的投稿信和选刊阻断已修改并只对受影响情境复测；其他六例未无故重复执行。

## 具体未验证部分

1. Word/Proof 测试确认生成文件、文字内容与修订结构；本轮没有调用 Word/LibreOffice 将这些 DOCX 渲染为页面，**不声称 Word 版面已经通过视觉验收**。包内说明要求实际使用时根据任务渲染，缺渲染器时明确报告。
2. 没有联网刷新期刊 JIF、APC、JCR、风险名单或数据库数据。包内风险参考是原作者历史快照；测试验证程序处理，不证明任何期刊当前状态。
3. 没有生成科学机制图、制作真实论文 PPT/XLSX、部署网站、创建定时任务、配置 GUI/远程服务或发送投稿。相应分支已纳入方法与真实依赖，需实际任务和可用宿主能力执行。
4. 核心写作与技能文件独立；Python 解释器、公共运行库、Office、模型账户、联网和宿主服务不在 ZIP 中。未将受限本机第三方 Word/PDF skill 作为成品依赖。
5. 没有安装到用户全局 skill 目录、修改全局角色目录/规则或创建任何新盘符映射。安装验证均在本构建目录的隔离位置进行。

最终 ZIP 的根目录、解压后安装和迁移脚本运行记录由 `scripts/make_release.py` 产生在 `validation/release_results.json`；该记录由最终封装步骤生成，避免在包内宣称未经执行的封装结果。
